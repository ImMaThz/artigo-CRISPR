## 📌 Sobre o projeto

Artigo de divulgação científica criado com o apoio de **IA generativa**, explicando de forma simples:

- o que é o CRISPR e de onde ele veio (o sistema imunológico das bactérias);
- como a "tesoura genética" funciona em 3 passos;
- a evolução da ferramenta: CRISPR-Cas9 → edição de bases → prime editing;
- casos reais: **Casgevy** (1ª terapia CRISPR aprovada), o **bebê KJ** (1ª terapia personalizada) e a primeira terapia **in vivo** em análise na FDA;
- os limites e dilemas éticos da edição genética.
